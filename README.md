# odin-rock-paper-scissors

This project is a simple static page with javascript that simulate a game of rock paper scissors.
This project uses lessons and skills learned from the Odin Project.

This project was made using the tools below.

- Git
- Github
- VS Code

Doing this project helped understand javascript as a scripting language, and taught me problem solving and simple algorithm design.
